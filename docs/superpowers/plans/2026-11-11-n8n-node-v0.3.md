# n8n-nodes-postsider 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship node version 2 (simple Publish with Now, implicit media upload, full API coverage) plus a polling PostSider Trigger, without changing version 1 behavior.

**Architecture:** `PostSider` node becomes `version: [1, 2]`, `defaultVersion: 2`. Existing v1 code stays where it is and is selected by `@version: [1]` display options and by `this.getNode().typeVersion < 2` in `execute`. All v2 code lives in `nodes/PostSider/v2/` as pure request builders (unit-tested) plus a thin executor. The trigger is a separate node in `nodes/PostSiderTrigger/`.

**Tech Stack:** TypeScript 5.9, n8n-workflow 2.46.5 (`sleep`, `NodeOperationError`, `NodeApiError`), `@n8n/node-cli` 0.55.5 (build, lint), tests with `tsx --test` and `node:assert/strict`.

**Spec:** `docs/superpowers/specs/2026-11-11-n8n-node-v0.3-design.md`

**Backend reference (read-only):** `../postsider/apps/backend/src/public-api/routes/v1/public.integrations.controller.ts`, `public.workspace.controller.ts`, provider DTOs in `../postsider/libraries/nestjs-libraries/src/dtos/posts/providers-settings/`.

## Global Constraints

- No runtime dependencies. `n8n-workflow` stays a peer + dev dependency only.
- Must pass `npm run verify` (lint, typecheck, tests, build). No `setTimeout`/`setInterval`/`process`/`globalThis` (community lint restricts them); wait with `sleep` from `n8n-workflow`.
- Validation errors: `NodeOperationError`. HTTP errors: `NodeApiError` (existing pattern in `PostSider.node.ts`).
- All requests go through `postSiderApiRequest` (`shared/transport.ts`) so base URL normalization, timeout 30 s and no-redirect rules stay.
- Version 1 parameters, defaults, names and outputs must not change. All 57 existing tests stay green unchanged (only import paths may move).
- Path ids are always `encodeURIComponent`-ed.
- Control-plane operations (Approval, Policy, Group, Post > Retry Failed) carry the description prefix exactly: `Requires PostSider server 2026-11 or newer. `
- Publishing resume is human-only on the backend: the node offers Get State and Pause only.
- Copy rules for user-facing text: no em or en dashes.
- Git binary on this host: `/Library/Developer/CommandLineTools/usr/bin/git`.

## Review Focus

1. Channels given by expression as a comma-separated string or a JSON array of ids: Publish must accept both, trim, drop empties, and fail with a clear `NodeOperationError` when nothing is left.
2. Binary property name that does not exist on the item: fail naming the property, before any post is created (no half-written posts).
3. Next free slot when the backend returns no date (`{date: null}` or missing): fail with a clear message, never publish now by accident.
4. Wait for Result with an ERROR row: return the row with `state: 'ERROR'` and its error text, not throw, so the workflow can branch.
5. Trigger first run in a fresh workflow: emits nothing on activation (no flood of old posts), and a post that moves QUEUE to PUBLISHED later is emitted exactly once.

### Task 2: Shared v2 input helpers and media upload

**Interfaces:**
- Produces in `inputs.ts`:
  - `parseIdList(node: INode, value: unknown, displayName: string): string[]` (accepts string[] / comma or newline string / JSON array string; trims, dedupes, drops empties; throws `${displayName} must list at least one value` when empty).
  - `parseUrlList(node: INode, value: unknown): string[]` (same splitting; every URL must be `https:` without credentials, message `Media URLs must be public HTTPS URLs`).

- Produces in `media.ts`:
  - `type ApiCall = <T>(method: IHttpRequestMethods, endpoint: string, input?: RequestInput) => Promise<T>` (export `RequestInput` from transport).
  - `uploadFromUrls(api: ApiCall, urls: string[]): Promise<PostSiderMedia[]>` sequential `POST /upload-from-url {url}`.
  - `uploadBinaries(ctx: IExecuteFunctions, api: ApiCall, itemIndex: number, propertyNames: string[]): Promise<PostSiderMedia[]>`: for each name, `ctx.helpers.assertBinaryData(itemIndex, name)` first for ALL names (fail before any upload), then `getBinaryDataBuffer`.   - `toMedia(response: unknown): PostSiderMedia` keeps `id`, `path`, plus `name`, `thumbnail`, `alt` when present; throws when id or path missing.
- Transport: `RequestInput` gains `formData?: FormData`; `buildRequestOptions` sends it as `body` without `json: true`.
